# autological

We automate processes logically. It's pretty self-explanatory.

A minimal, responsive static landing page using the supplied autological logo and the Comfortaa typeface from Google Fonts. No build step or dependencies required.

## Development

Open `index.html` in a browser, or serve this directory with any static HTTP server. Edit `index.html` for content and `styles.css` for presentation. The original supplied logo is in `assets/logo.png`.

## Publishing

GitHub Pages publishes the root of the `main` branch at https://autological-eu.github.io/hello/ when Pages is enabled. Push changes to `main` to update the site.

The site respects reduced-motion preferences and uses relative asset paths so it works under the `/hello/` project path. It contains no analytics or tracking scripts. Google Fonts is the only external page dependency; a local sans-serif fallback is used if unavailable.
